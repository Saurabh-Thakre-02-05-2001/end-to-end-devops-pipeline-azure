ABSTRACT

The rapid growth of digital commerce has necessitated the development of robust, scalable, and secure web applications capable of handling complex business transactions. This project, ShopKart, is a full-stack e-commerce web application designed using Spring Boot 3.3.4 and the Java ecosystem.

The primary objective of the study is to create a multi-user platform with distinct roles for Customers and Administrators. The application implements the Model-View-Controller (MVC) architectural pattern, utilizing JavaServer Pages (JSP) for dynamic server-side rendering and Spring Data JPA for persistent data management in a relational database mapping environment.

Key features include a secure customer registration and login system protected by BCrypt password hashing, a comprehensive product catalog with search and filtration capabilities, an interactive shopping cart with stock-aware validation, and a detailed order management workflow. For administrators, a data-driven dashboard provides real-time analytics on sales trends, inventory health, and customer activity.

The project highlights the implementation of layered architecture and dependency injection to ensure codebase maintainability. Testing was conducted across registration, catalog management, and order placement modules to ensure functional reliability. Future enhancements involve integrating real-time payment gateways and migrating to a decoupled React-based frontend for enhanced performance.

CHAPTER 1
INTRODUCTION

1.1 Background

In the last decade, the retail electronics market has witnessed a paradigm shift from physical storefronts to digital marketplaces. With the increasing penetration of high-speed internet and the proliferation of smartphones, consumers now demand 24/7 access to product catalogs from the comfort of their homes. This digital transformation is not merely a convenience but a necessity for businesses to remain competitive. Building such a platform requires a robust backend capable of handling multiple concurrent users, complex inventory logic, and secure authentication.

Java, through the Spring Boot framework, has emerged as a leader in this domain. Spring Boot simplifies the development of production-ready applications by providing auto-configuration, an embedded server, and a vast ecosystem of starter modules for database interaction and security. ShopKart is born out of this technological landscape, aiming to provide a high-performance, easy-to-manage web application for e-commerce.

1.2 Problem Statement

Traditional e-commerce development often suffers from tight coupling between the user interface and business logic, leading to maintenance challenges. Furthermore, academic prototypes often focus heavily on the frontend while neglecting the essential backend constraints such as:

  • Secure password management and session handling.
  • Accurate stock tracking during concurrent orders.
  • Distinction between high-privileged administrative actions and standard customer browsing.

ShopKart addresses these problems by implementing a strictly layered architecture using Spring Boot, ensuring that each module is independent and scalable.

1.3 Objectives

The primary objectives of this project are:

  • To design and implement a secure authentication module using BCrypt hashing.
  • To develop a responsive product catalog with dynamic search and category filtering.
  • To create an automated shopping cart system that validates stock levels in real-time.
  • To build an Admin Dashboard that provides data visualization for business intelligence.
  • To ensure the entire system is deployable using containerization (Docker).

LITERATURE REVIEW

2.1 Existing Systems

Market leaders like Amazon and Flipkart utilize highly distributed microservices architectures. While these systems are highly scalable, they are extremely complex for small-to-medium scale deployments. On the other hand, many legacy PHP-based systems use outdated procedural code which is difficult to secure.

Comparative study of different frameworks:

PHP (Laravel) High Medium Medium
Spring Boot (Java) Medium Very High Very High
Node.js (Express) High High Medium

2.2 Gaps and Proposed Solution

Many academic projects lack a proper administrative control panel or utilize plain-text password storage. ShopKart bridges these gaps by including a Security Key based administrative login and Hibernate-based persistence for data integrity. The proposed system is a monolithic MVC application that provides the robustness of Enterprise Java with the simplicity of Spring Boot.

CHAPTER 3
SYSTEM ANALYSIS AND DESIGN

3.1 Requirements Analysis

3.1.1 Functional Requirements

  • User Registration: Users must be able to sign up with unique emails.
  • Authentication: Secure login for both Customers and Admins.
  • Catalog Management: Admin must be able to Add/Update/Delete products.
  • Order Lifecycle: Cart management, order placement, and status updates (Shipped/Delivered).

3.1.2 Non-Functional Requirements

  • Security: All passwords must be hashed. CSRF protection is simulated.
  • Availability: The system should handle concurrent requests without database deadlocks.
  • Portability: Run on any OS with Java 17 and Docker.

CHAPTER 4
DESIGN AND IMPLEMENTATION

4.1 Implementation Strategy

The implementation was carried out in a modular fashion. I started with the Model layer using Java Persistence API (JPA), followed by the Repository interfaces for CRUD operations. The Service layer was then developed to handle edge cases like stock validation. Finally, the Controller and JSP Views were mapped to these services.

4.1.1 Code Snippet - Security Configuration

The following code snippet demonstrates the custom security filter chain configuration.

@Bean public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception { http.csrf(csrf -> csrf.disable()) .authorizeHttpRequests(auth -> auth .requestMatchers("/**").permitAll() .anyRequest().authenticated() ) .headers(headers -> headers.frameOptions(frame -> frame.disable())); return http.build(); }

4.1.2 Code Snippet - Order Processing

Logic for converting cart items into orders while reducing stock.

@Transactional public void placeOrder(Customer customer) { List<CartItem> items = cartRepository.findByCustomer(customer); for (CartItem item : items) { Order order = new Order(); order.setProduct(item.getProduct()); order.setQuantity(item.getQuantity()); order.setStatus(OrderStatus.Pending); orderRepository.save(order); // Reduce stock item.getProduct().setStock(item.getProduct().getStock() - item.getQuantity()); } cartRepository.deleteAll(items); }

CHAPTER 6
CONCLUSION AND FUTURE WORK

6.1 Conclusion

The ShopKart project successfully met all its primary objectives. We developed a secure, scalable, and easy-to-use e-commerce application using the Spring Boot framework. By utilizing Hibernate and MySQL, we ensured data persistence and transactional integrity. The project serves as a comprehensive example of how Enterprise Java solutions can be applied to modern web problems.

6.2 Challenges Overcome

  • Implementing custom session-based authentication without standard Spring Security Login.
  • Handling file I/O for profile and product images in a generic way.
  • Designing a responsive UI using only JSP and standard CSS.

6.3 Future Work

  • Payment Gateway: Integrating Razorpay or Stripe for real-world transactions.
  • Microservices: Breaking down the monolith into User, Order, and Catalog services.
  • Mobile App: Developing a React Native client that consumes REST APIs from this backend.
